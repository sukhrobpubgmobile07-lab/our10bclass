OUR CLASS — инструкция

1. Распакуйте архив.
2. Откройте папку our_class_website.
3. Дважды щёлкните по index.html — сайт откроется в браузере.
4. Чтобы редактировать сайт, откройте index.html в Visual Studio Code или Блокноте.

Что изменить в первую очередь:
- Найдите в HTML блок people-grid и замените демонстрационные имена на имена одноклассников.
- Найдите число 24 в блоке studentCount и укажите реальное количество учеников.
- Замените текстовые карточки галереи своими событиями.
- Чтобы добавить фотографии, положите изображения в папку images и вставьте в нужный блок тег:
  <img src="images/class-photo.jpg" alt="Наш класс">

Важно:
- Не публикуйте личные номера телефонов, адреса и другие приватные данные.
- Перед размещением фотографий одноклассников получите их согласие (а для несовершеннолетних — согласие родителей/опекунов, если требуется).

Внешний шрифт Google Fonts загружается из интернета; без интернета сайт всё равно откроется, но будет использован системный шрифт.
